プライバシーポリシー

AI Morning Cast / 最終更新日: 2026年8月16日

「AI Morning Cast」(以下「本アプリ」)は、ニュースの収集と読み上げを行う個人開発のアプリです。本ポリシーでは、本アプリが取り扱う情報について説明します。

1. 開発者が収集する情報

本アプリには会員登録・ログイン機能がなく、開発者が運営するサーバーも存在しません。そのため、開発者が氏名・メールアドレスなどの個人情報を直接収集することはありません。

2. 端末内に保存される情報

以下の情報は、すべてお使いの端末の中にのみ保存されます。外部のサーバーへ送信されることはありません。

  • 登録したキーワード・関心事項
  • 生成した番組の履歴(最大30件、古いものから自動削除)
  • 読み方辞書・音声設定(声の高さ・速さ など)
  • お客様ご自身が入力したAIサービスのAPIキー(後述)

アプリを削除、または端末の「設定」からアプリのデータを消去すると、これらの情報はすべて削除されます。

3. 広告について

本アプリは、Google AdMobを通じて広告を表示し、収益の一部としています。広告配信にあたり、Google および広告配信パートナーは、広告ID等の識別子を使用して、広告の表示・測定・不正防止を行う場合があります。

Googleによるデータの取り扱いについては、以下をご確認ください。

Google のパートナー向けポリシー

4. ニュース情報の取得

本アプリは、Google ニュース(RSS)から、お客様が登録したキーワードに基づいてニュース記事の見出しを取得します。この通信はお客様の端末から直接行われ、開発者を経由しません。

5. AIサービスとの連携(任意)

本アプリでは、番組の台本をより自然にするため、以下のAIサービスのAPIキーをお客様ご自身の判断で任意に設定できます。

  • Google Gemini API
  • Anthropic Claude API
  • OpenAI API
  • OpenRouter

APIキーを設定した場合、ニュースの見出しなどの情報が、お客様の端末から直接選択したAIサービスへ送信され、台本が生成されます。この通信は開発者を経由せず、開発者がその内容を閲覧・保存することもありません。各サービスにおけるデータの取り扱いは、それぞれの提供元のプライバシーポリシーに従います。APIキーを設定しない場合(「かんたんモード」)、この通信は行われません。

6. 通知機能について

本アプリは、お客様が設定した時刻・曜日に基づき、端末内でローカル通知を送る機能を提供します。この機能は端末内で完結しており、外部への情報送信は行いません。

7. 第三者への提供

開発者が、お客様の情報を第三者に販売・提供することはありません(第3項の広告配信、第5項でお客様ご自身が選択したAIサービスへの通信を除く)。

8. お子様のご利用について

本アプリは13歳未満のお子様を主な対象として設計されていません。お子様の個人情報を意図的に収集することはありません。

9. 本ポリシーの変更

本ポリシーの内容は、法令の改正や機能追加に伴い変更されることがあります。重要な変更がある場合は、本ページ上で更新します。
